# Temperature Converter

## Project Overview

Temperature Converter is a responsive web application developed as part of the Oasis Infobyte Web Development and Designing Internship. The application allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin.

## Objective

The objective of this project is to develop a simple, attractive, and user-friendly temperature conversion tool using HTML, CSS, and JavaScript.

## Features

* Convert temperature between Celsius, Fahrenheit, and Kelvin
* Input validation for invalid values
* Absolute zero validation
* Responsive design for different screen sizes
* Clean and modern user interface
* Instant conversion using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Conversion Supported

* Celsius to Fahrenheit and Kelvin
* Fahrenheit to Celsius and Kelvin
* Kelvin to Celsius and Fahrenheit

## Validation

The application checks for invalid or empty input and prevents temperatures below absolute zero.
