# StudyMate – Student Study Planner

## Project Overview

StudyMate is a responsive student study planner landing page designed to help students organize their study routine, track their progress, and stay focused on their academic goals.

## Features

* Responsive navigation bar
* Hero section with call-to-action button
* Study progress preview
* Study Planner feature
* Progress Tracking feature
* Focus Sessions feature
* Student Dashboard
* Student profile section
* Subject-wise progress tracking
* Today's study tasks with interactive checkboxes
* Dynamic progress calculation using JavaScript
* Responsive design for different screen sizes
* Smooth scrolling navigation
* Call-to-action section

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` in a web browser.
3. The StudyMate landing page will be displayed.
4. Explore the navigation, features, dashboard, and interactive study tasks.
